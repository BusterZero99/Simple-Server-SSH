# Simple-Server-SSH
A simple script to connect to a server or other computer on the same network using SSH.
This is only usable to run on Windows devices.

To use, change the MAC Address and IP address and Username to the one of the computer that you want to connect to.

It requires this exe to be able to do the Wake On Lan:
https://www.majorgeeks.com/files/details/gammadyne_wake_on_lan.html
